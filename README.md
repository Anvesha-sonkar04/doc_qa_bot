# Document Q&A Bot

An AI-powered document question-answering system that uses semantic search and Retrieval-Augmented Generation (RAG) to answer questions from PDF documents.

## Features

- PDF text extraction
- Text cleaning and chunking
- Semantic embeddings using Sentence Transformers
- Vector similarity search using FAISS
- Retrieval evaluation using Recall@3
- Question answering using a pretrained language model
- Source document and page number attribution
- Streamlit web interface

## Tech Stack

- Python
- Google Colab
- PyMuPDF
- Pandas
- Sentence Transformers
- FAISS
- Hugging Face Transformers
- Streamlit
